## 🎯 What I Do

### 🌐 Full Stack Development

Design and ship complete applications — responsive React front-ends, REST APIs on
Node/Express, and relational or document data layers. Comfortable owning a feature
from schema design through deployment.

### 🤖 Generative AI

Build LLM-powered features: prompt engineering, structured output, retrieval-augmented
generation over custom knowledge bases, and streaming interfaces that feel responsive.

### 🧠 Agentic AI

Move beyond single prompts to **autonomous agents** — tool and function calling,
memory, planning loops, and guardrails so an agent can reason through a task rather
than answer a question.

### 🕸️ Multi-Agent Systems

Compose specialised agents into **coordinated teams** — supervisor/worker hierarchies,
shared state, message passing, and hand-offs — to break large problems into steps that
run in parallel and verify each other.

### ☁️ Cloud & DevOps

Containerise with **Docker**, orchestrate with **Kubernetes**, and deploy on **AWS**
with CI/CD via GitHub Actions.
